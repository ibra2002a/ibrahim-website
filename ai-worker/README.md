# المساعد الذكي (AI) — تركيب الـ Worker

المساعد بالموقع يشتغل من الآن **بوضع موجّه** (مجاني، بدون أي إعداد).
حتى يصير **ذكاء اصطناعي حقيقي** يجاوب على أي سؤال، تحتاج هذا الوسيط الصغير على Cloudflare (مجاني لحد 100 ألف طلب باليوم). هو يحمي مفتاح الـ AI حتى محد يسرقه.

## 1) مفتاح الذكاء الاصطناعي (اختار وحدة)

| الخيار | الكلفة | من وين |
|---|---|---|
| **Gemini** (Google) | فيه مستوى مجاني محدود | aistudio.google.com ← Get API key |
| **Claude** (Anthropic) | مدفوع حسب الاستخدام (رخيص جدًا لمحادثات قصيرة) | console.anthropic.com ← API Keys |

> مع Claude: حط حد صرف شهري (Spend limit) من إعدادات الحساب حتى تبقى الكلفة تحت السيطرة.

## 2) إنشاء الـ Worker (من المتصفح، بدون برامج)

1. ادخل **dash.cloudflare.com** وسوّي حساب مجاني.
2. **Workers & Pages** ← **Create** ← **Create Worker** ← الاسم: `ibrahim-ai` ← **Deploy**.
3. اضغط **Edit code**، احذف الكود الموجود، والصق محتوى ملف `worker.js` كامل ← **Deploy**.
4. ارجع للـ Worker ← **Settings** ← **Variables and Secrets** ← ضيف:
   - `SITE_URL` = `https://ibra2002a.github.io/ibrahim-website`
   - `ALLOWED_ORIGIN` = `https://ibra2002a.github.io`
   - **Secret**: `GEMINI_API_KEY` **أو** `ANTHROPIC_API_KEY` = المفتاح
5. انسخ رابط الـ Worker (يشبه `https://ibrahim-ai.xxxx.workers.dev`).

## 3) الربط بالموقع

**لوحة التحكم ← الإعدادات ← المساعد الذكي** ← الصق الرابط ← **اختبار** (لازم يطلع ✓ شغال) ← **حفظ ونشر**.
بعد دقيقتين المساعد بالموقع يصير يجاوب بالـ AI.

## الحماية المطبّقة

- المفتاح محفوظ كـ Secret بـ Cloudflare، ما يوصل للمتصفح أبدًا.
- الـ Worker يقبل طلبات من موقعك بس (`ALLOWED_ORIGIN`).
- حدود: آخر 10 رسائل، 800 حرف للسؤال، جواب قصير، و15 سؤال بالجلسة من جهة الموقع.
- المساعد مبرمج ما يخترع أسعار أو نتائج، ويحوّل الأسئلة الخاصة لك على الواتساب.
- معرفة المساعد تتحدث تلقائيًا من محتوى الموقع (`assets/ai-knowledge.json`)؛ أي تعديل باللوحة يوصله خلال دقائق.

اختياري: من Cloudflare ← Security ← WAF ← Rate limiting rules، حدد مثلًا 20 طلب بالدقيقة لكل IP.
